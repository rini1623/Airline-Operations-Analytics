# Airline Operations, Delay & Customer Experience Analytics

## 📌 Project Overview

This project analyzes airline flight operations using SQL and Python to identify flight patterns, delay trends, route activity, airport performance, and major causes of delays.

The project combines MySQL for data querying and analysis with Python libraries for data analysis and visualization.

## 🎯 Objectives

- Analyze overall airline flight operations
- Compare departure and arrival delays
- Identify busiest flight routes
- Analyze airport-wise performance
- Identify major causes of flight delays
- Compare on-time and delayed flights
- Analyze monthly delay patterns
- Study taxi and flight-duration patterns

## 🛠️ Technologies Used

- MySQL
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Dataset

The dataset contains flight information including:

- Flight date
- Airline
- Origin and destination airports
- Departure and arrival times
- Departure and arrival delays
- Flight distance
- Air time
- Taxi time
- Cancellation and diversion information
- Delay causes

## 📈 Key Findings

- The dataset contains 161,023 flight records.
- It covers 18 airlines.
- There are 377 origin airports and 372 destination airports.
- Average departure delay is 10.16 minutes.
- Average arrival delay is 4.37 minutes.
- Average flight distance is 809.58.
- No cancelled or diverted flights are present in this particular dataset sample.

## 💡 Conclusion

The analysis provides an operational view of airline performance by examining flight volume, delays, routes, airports, delay causes, and ground operations.

The combination of SQL and Python demonstrates how data analysis can be used to identify operational patterns and generate meaningful insights.
